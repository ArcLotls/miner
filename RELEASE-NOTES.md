# ArcLotls miner 0.1.0-preview.2

Portable Windows and Linux x64 downloads with a bundled runtime, CUDA/WebGPU/CPU engines, and browser MetaMask signing. Extract the platform archive and follow START-HERE.md. Every mint requires confirmation.

This revision minimizes mining configuration and removes deployment-wide verification from the standalone miner. Wallet network/account checks, transaction simulation, challenge freshness, proof verification, and pending-transaction recovery remain enabled.

Release archives are screened for prohibited build metadata, personal paths, common credential patterns, unexpected files, and unsafe Linux permissions. Screening does not guarantee absence of vulnerabilities or prevent reverse engineering or on-chain identity correlation. Public contract addresses and readable application code remain in the download.

This preview is unsigned. SHA-256 checksums detect changed bytes; they do not authenticate the publisher. No build provenance attestation is published. See COMPATIBILITY.md for hardware limitations.
